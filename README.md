A fully interactive cyberpunk-themed personal portfolio website built with **HTML, CSS & JavaScript** — featuring Matrix rain, boot screen animation, neon glow effects, project modals, and mouse trail.

## 🚀 Features

- ⚡ Matrix rain canvas background
- 🖥️ Hacker terminal boot screen
- 🖱️ Neon mouse trail (desktop)
- 📋 Interactive project detail modals with typing animation
- 🌐 Active On section — GitHub, LinkedIn, TryHackMe, HackTheBox, LeetCode
- 📜 12 Certificates with direct view links
- 💾 Resume download
- 🎨 Cyan/Electric Blue `#00d9ff` cyberpunk theme
- 🔤 JetBrains Mono + Inter typography
- 📱 Fully responsive

## 🛠️ Tech Stack
`HTML5` `CSS3` `Vanilla JavaScript` `Canvas API`
